# SOP Pengembangan & Kontribusi Proyek

Semua pengembang dan agen AI wajib mematuhi aturan berikut:

1. **Localhost-First:** Semua perubahan harus diuji di server lokal (`localhost:4000`).
2. **No Unauthorized Push:** Dilarang melakukan `git push` ke branch `main` tanpa persetujuan langsung dari pemilik proyek.
3. **Build Integrity:** Selalu pastikan `npm run build` sukses sebelum meminta izin rilis produksi.
